# MARS

MARS is a TanStack Start website for a robotics investment and deployment studio.

## Requirements

- Node.js 20 or newer
- npm

## Local development

```sh
npm install
npm run dev
```

The development server runs on the port reported by Vite.

## Production validation

Run the complete local quality gate before deploying:

```sh
npm run check
```

This runs ESLint, TypeScript checking, and the test suite. Build the production
bundle with:

```sh
npm run build
```

The generated deployment bundle is written to `.output/`. This directory is
ignored by Git and must be regenerated by the deployment pipeline.

## Cloudflare deployment

The project is configured by TanStack Start to generate a Cloudflare-compatible
Nitro bundle. Authenticate Wrangler before the first deployment:

```sh
npx wrangler login
npm run deploy:cloudflare
```

`deploy:cloudflare` runs the quality gate and production build before invoking
Wrangler, so a deployment cannot proceed when checks fail. Configure the
production domain and any platform-specific variables in the Cloudflare
dashboard or Wrangler configuration; do not commit secrets to this repository.
